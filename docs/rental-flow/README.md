## 1. REWIND のページで「よくできている」ところ

| # | よい点 | なぜ効くか |
|---|---|---|
| 1 | **4ステップの目次**（予約する→受け取る→並べて撮る→返送する）を最初に置いている | 全体像が一目でわかり、読みたい所へ飛べる |
| 2 | 「予約する」を**5つの小さな手順**（選ぶ→日程→オプション→支払い→発送メール）に分けている | 初めての人が「次に何が起きるか」で迷わない |
| 3 | 操作画面の**スクリーンショット**を入れている | カレンダーの操作など、文章より早く伝わる |
| 4 | **2泊3日のスケジュール**を Day1/2/3 の時系列で見せている | 「いつ届いて、いつ撮って、いつ返すのか」が一目でわかる |
| 5 | **発送元と、北海道・沖縄の追加送料**を明記 | 注文前の不安や、後からの問い合わせが減る |
| 6 | **返送する箱のサイズ表**＋送料を調べるリンク | 返送料を事前に見積もれる |
| 7 | **「困ったときは」**（メールが来ない／届かない／壊した／遅れそう）を、すべて公式LINEへ誘導 | 問い合わせの入口が1つにまとまる |
| 8 | 最後に情景が浮かぶ一文＋「セットを見る」ボタン | 読み終えた人をそのまま商品ページへ戻す |

## 2. gri がすでに勝っているところ（もっと前に出す）

REWIND は破損補償が**有料オプション**、返送は**ヤマトのみ・17時まで**です。gri はそこが強みなので、ページの冒頭にまとめて置きました（下書きの緑の枠）。

- 破損してもご負担0円（保証が料金に含まれている）
- 返送の配送業者は自由、集荷でも持ち込みでもOK、**最大19時まで**
- 返送をLINEで報告すると**次回1,000円OFF**

## 3. gri 向けに変えたところ

- **スケジュール**：gri は「前日着 → ご利用日 → 返送日」なので、2日目（ご利用日）を強調
- **03 飾って撮る**：LINEのC-2で送っている撮影のコツ3つ（自然光／30cm手前／引きと寄り）を流用。ページとLINEで言うことがそろう
- **04 返送する**：同梱カード裏面・C-3の「返却3ステップ」と同じ順番にし、4つ目に「LINEで返送を報告」を追加
- **注文後の流れ**：STORES の注文とLINEは自動でつながらないので、「ご注文の報告」をページ内でも案内（3段構えの入口を1つ増やす）
- **お助けアイテム**（クーファン・バンボ・チェア）をオプションとして紹介

## 4. 埋めてほしい情報（下書きの黄色い部分）

- [ ] 発送元の都道府県
- [ ] 北海道・沖縄・離島の追加送料
- [ ] 返送する箱のサイズとデザインの対応表
- [ ] 延長料金（1日あたり）
- [ ] LINEの返信時間・返信の目安
- [ ] LINE の URL（注文報告／返送報告／問い合わせ）、STORES の商品一覧 URL
- [ ] 写真・スクリーンショット（デザイン一覧、日程を選ぶ画面、オプション画面、開封時、ご利用写真）

## 5. STORES に載せるときの進め方

1. STORES のページ編集機能で、見出し・文章・画像のブロックを下書きの順に並べる（見た目はテーマに合わせてOK。大事なのは**順番と中身**）
2. 目次（01〜04）は、ページ内リンクが使えなければ省略し、見出しに番号を付けるだけでも十分
3. 「困ったときは」は、LINEのFAQ自動応答と同じ答えにそろえる
4. 公開後、各商品ページの説明文の最後に「レンタルの流れはこちら」のリンクを置く
